# FTC Launchpad

A centralized hub for FTC rookie teams, new members, and students interested
in joining or starting an FTC team.

## Features
- Step-by-step guides for starting a team
- Resources for programming, build, CAD, and outreach
- Guidance for finding and joining nearby teams

## Team ownership verification

Existing team listings are verified with a one-time code sent to the public
email on the team’s FIRST Dashboard profile. Team records and public email
addresses are resolved through FIRST’s public team search endpoint. The normal
site email configuration is used to deliver the code; no separate OAuth client
or team-verification credentials are required.
